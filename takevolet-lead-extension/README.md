# 🚀 Takevolet Real Estate Lead Clipper & Messenger Extension

A specialized Chrome / Brave / Edge extension designed for real estate sales executives and admins to capture property buyer leads directly from social media (Instagram, YouTube, Facebook) into the **Takevolet CRM**, generate instant personalized conversion messages, and open direct messaging with 1 click.

---

## 🛠️ How to Install in Chrome / Brave / Edge (3 Steps)

1. Open **Google Chrome** (or Brave / Edge / Arc).
2. Go to `chrome://extensions/` in the URL bar.
3. Turn on **Developer mode** (toggle in the top-right corner).
4. Click **Load unpacked** (top-left button).
5. Select the folder:
   ```
   c:\homies rentals\roomrelay\takevolet-lead-extension
   ```
6. The extension is now installed! Pin it to your browser toolbar for quick access.

---

## 💡 How It Works

### 1. Clip Lead from Instagram / Social Media
* When viewing an Instagram profile, reel, or property post with comments:
* Click the **Takevolet** extension icon.
* Click **⚡ Detect from Tab** (auto-fills profile handle & source post URL).
* Select the **Hyderabad Area** (e.g. Gachibowli, Kokapet, Financial District, Tellapur) and **Category** (Buy Flat, Villa, Plot, Rental).
* Paste any comment text or budget note.
* Click **💾 Save Lead to Takevolet CRM**.

### 2. Instant Outreach Message Assistant
* The extension automatically generates a high-converting message customized with the lead's name and location.
* Click **📋 Copy Message** (copies to clipboard).
* Click **💬 Open DM Chat** (instantly opens `https://ig.me/m/username` to paste and send your message).

### 3. CRM Dashboard Synchronization
* View all captured leads directly in the extension popup under the **CRM Leads** tab.
* View, filter, and manage lead status (New ➔ Contacted ➔ Qualified ➔ Closed) directly in the **Takevolet Web Admin Panel** under the **Social Leads CRM** tab (`/admin`).
